## 오늘 개선 대상으로 고른 이유
최근 21:00 품질 개선 이력이 체지방률, 비상가방, 포모도로, 주차요금, 더치페이, 대출 계산기 등에 집중되어 있어 같은 툴 반복을 피했습니다.
분수 계산기는 **분모 0, 0으로 나누기, 음수 부호, 붙여넣은 식 처리처럼 오류 가능성이 큰 입력 경계값이 많고, 모바일에서 네 칸 입력 흐름을 더 줄일 여지가 커서** 오늘 개선 대상으로 골랐습니다.

## 분수 계산기, 이런 때 바로 써요
문제집을 풀거나 레시피 비율을 계산할 때,
분수끼리 더하고 빼는 건 물론이고 **최종 결과를 약분해서 다시 확인하는 과정**이 은근 번거롭습니다.

이 도구는 두 분수를 입력하면 사칙연산 결과를 계산하고,
**약분 결과 / 대분수 / 소수 / 백분율**까지 한 화면에서 바로 보여줍니다.
`1/2 + 1/3`, `-7/12 + 5/8`, `3/4 ÷ 2/5`처럼 한 줄 식을 붙여넣은 뒤 바로 입력칸으로 반영할 수도 있습니다.

## 핵심 기능
- 분수 덧셈·뺄셈·곱셈·나눗셈 지원
- 빠른 식 입력으로 `분자/분모 연산 분자/분모` 형태 붙여넣기 지원
- 결과 분수 자동 약분
- 대분수 형태 함께 표시
- 소수값과 백분율 동시 확인
- 음수 분모 부호 정리, 분모 0, 0 나눗셈, 범위 초과 입력 안내
- 결과 복사 버튼 제공

## 사용 방법
1. `1/2 + 1/3`처럼 빠른 식을 입력해 반영하거나, 첫 번째 분자의 값과 분모를 직접 입력합니다.
2. 연산 기호를 선택합니다.
3. 두 번째 분자의 값과 분모를 입력합니다.
4. 약분 결과, 대분수, 소수, 백분율을 확인합니다.

분수 위치를 바꾸면 결과가 달라지는 뺄셈·나눗셈은 **분수 위치 바꾸기** 버튼으로 순서를 빠르게 비교할 수 있습니다. 정확한 계산을 위해 분자와 분모에는 -10,000,000부터 10,000,000 사이의 정수를 입력해 주세요.
분모에 음수 부호가 붙은 `1/-2` 같은 입력은 **부호 정리** 버튼으로 `-1/2` 형태로 맞출 수 있습니다.

## FAQ
### 결과가 왜 대분수로도 나오나요?
가분수를 바로 해석하기 어렵다면 정수부와 분수부를 나눈 대분수 형태가 더 직관적이기 때문입니다.

### 음수 분수도 계산할 수 있나요?
네. 분자에 음수를 넣으면 음수 분수 계산도 가능합니다.

### 소수나 아주 큰 수도 입력할 수 있나요?
이 계산기는 정수로 이루어진 분수를 정확하게 약분하는 도구입니다. 소수 입력은 지원하지 않으며, 정밀도 오류를 막기 위해 각 입력값은 절댓값 10,000,000 이하로 제한합니다.

### 빠른 식 입력에서 쓸 수 있는 연산자는 무엇인가요?
더하기 `+`, 빼기 `-`, 곱하기 `×` 또는 `*`, 나누기 `÷` 또는 `/`를 쓸 수 있습니다.

### 백분율은 어디에 쓰면 좋나요?
시험 점수 비율, 혼합 비율, 할인율처럼 분수를 퍼센트로 바로 해석해야 할 때 편리합니다.
