## 오늘 개선 대상으로 고른 이유
최근 21:00 품질 개선은 `volumetric-weight-calculator`, `recycling-sorting-checker`, `movie-seat-choice-simulator`, `fuel-economy-calculator`, `image-resizer`처럼 다른 계산·체커·이미지 도구에 집중되어 있어 같은 툴 반복을 피했습니다.
`list-format-converter`는 메신저·스프레드시트·README에서 복사한 목록에 줄바꿈, 탭, 쉼표, 따옴표, 빈값, 중복이 섞이기 쉬운 converter형 도구라 오류 테스트와 모바일 입력 흐름 개선 가치가 커 오늘 대상으로 골랐습니다.

## 왜 목록 형식 변환기가 필요할까요?
메신저나 메모장에 적어둔 줄글 목록을 업무 문서, 블로그 글, 스프레드시트, 개발 문서에 붙여넣으려면 형식을 다시 맞추는 시간이 은근히 듭니다. 항목마다 번호를 붙이고, CSV로 쉼표를 이스케이프하고, 마크다운 표의 구분선을 넣는 작업은 단순하지만 반복되기 쉽습니다.

이 도구는 한 줄에 하나씩 적힌 목록뿐 아니라 쉼표나 탭으로 붙어 있는 목록도 **CSV, 마크다운 표, JSON 배열, 번호 목록**으로 바로 바꿔줍니다. 구분 기준 자동 감지와 따옴표 쉼표 파싱을 지원해 스프레드시트에서 복사한 후보 목록이나 채팅으로 받은 `A, "B, C", D` 같은 입력도 더 안전하게 정리할 수 있습니다.

## 어떻게 쓰나요?
1. 변환할 목록을 한 줄에 하나씩 붙여넣거나, 쉼표·탭으로 이어진 목록을 붙여넣습니다.
2. 입력 구분 기준을 자동 감지로 두거나 줄바꿈, 쉼표, 탭 중 직접 고르고 결과 형식을 CSV, 마크다운 표, JSON 배열, 번호 목록 중에서 선택합니다.
3. 필요하면 빈 줄 제거, 앞뒤 공백 제거, 중복 항목 제거 옵션을 켭니다.
4. `목록 변환`을 누르고 결과를 확인합니다.
5. 복사 버튼으로 문서, 스프레드시트, 노션, README 등에 붙여넣습니다.

## 이런 상황에서 특히 유용해요
### 1) 메모 목록을 스프레드시트에 넣을 때
줄글 목록을 CSV로 바꿔 복사하면 스프레드시트나 표 편집기에 붙여넣기 쉽습니다.

### 2) README나 블로그에 표를 만들 때
항목 목록을 마크다운 표로 바꾸면 구분선과 행 형식을 매번 손으로 만들지 않아도 됩니다.

### 3) 개발 문서나 자동화 입력값을 만들 때
목록을 JSON 배열로 바꾸면 간단한 설정값, 테스트 데이터, 샘플 입력을 빠르게 준비할 수 있습니다.

### 4) 쉼표로 받은 후보 목록을 다시 정리할 때
메신저에서 `A, B, C`처럼 받은 후보를 쉼표 기준으로 나눠 번호 목록이나 JSON 배열로 바꿀 수 있습니다.

### 5) 스프레드시트에서 복사한 탭 목록을 정돈할 때
한 열을 복사하면 탭이나 줄바꿈이 섞일 수 있습니다. 자동 감지를 켜면 입력 모양에 맞춰 구분 기준을 먼저 잡아주므로 결과 형식 선택에 집중할 수 있습니다.

## FAQ
### 쉼표가 들어간 항목도 CSV로 바뀌나요?
네. 쉼표, 따옴표, 줄바꿈이 포함된 항목은 CSV 규칙에 맞춰 따옴표로 감싸고 내부 따옴표를 이스케이프합니다.

### 중복 항목은 어떻게 처리하나요?
`중복 제거` 옵션을 켜면 정리된 문구 기준으로 같은 항목을 한 번만 남깁니다. 원래 순서는 최대한 유지합니다.

### 아주 긴 목록도 한 번에 변환할 수 있나요?
입력은 최대 30,000자이며, 브라우저가 멈추지 않도록 한 번에 처음 1,000개 항목까지 변환합니다. 그보다 긴 목록은 여러 번 나눠 처리하는 편이 좋습니다.

### 민감한 목록을 넣어도 되나요?
도구가 서버로 전송하지는 않지만, 계정 정보나 개인정보처럼 민감한 내용은 가능하면 넣지 않는 편이 안전합니다.
