## 오늘 개선 대상으로 고른 이유
최근 명시적인 품질 개선은 `korean-name-romanizer`, `png-compressor`, `json-merge`, `link-list-cleaner` 등에 집중되어 있어 같은 툴 반복을 피했습니다.
시간 차이 계산기는 **자정 넘김, 같은 시각, 종료가 더 빠른 입력, 휴게시간 과다 입력처럼 실제 사용 중 오류 가능성이 높은 경계값이 많고, 모바일에서 예시 입력과 결과 상태가 더 명확해질 여지가 커서** 오늘 개선 대상으로 골랐습니다.

## 시간 차이 계산기, 언제 쓰면 좋을까요?
두 시각 사이가 **정확히 몇 시간 몇 분인지** 바로 확인해야 할 때가 자주 있습니다.
근무시간 정산, 공부 시간 기록, 일정 간격 확인, 상담/회의 소요시간 계산처럼
생각보다 손으로 계산하기 번거로운 상황이 많습니다.

이 도구는 **시작 시각 + 종료 시각**만 입력하면
- 총 경과시간
- 총 분
- 소수 시간
- 휴게시간 제외 순수 시간
- 자정 넘김/당일 날짜 처리
를 한 번에 보여줍니다.

## 핵심 기능
- 시작 시각/종료 시각 입력
- 자정 넘김(다음 날 종료) 계산 지원
- 총 시간·분·소수 시간 자동 계산
- 휴게시간(분) 차감 후 순수 시간 계산
- 종료 시각이 시작보다 빠른 입력, 과도한 휴게시간, 빈값 오류 안내
- 근무일·자정 넘김·회의 시간 예시 버튼
- 결과 복사 버튼 제공

## 이런 상황에서 특히 유용해요
### 1) 출근·퇴근 사이 실제 근무시간을 빠르게 볼 때
09:00부터 18:00까지의 총 시간과 휴게시간 60분을 뺀 순수 시간을 한 번에 확인할 수 있습니다.

### 2) 야간 근무나 늦은 일정처럼 자정을 넘길 때
23:30부터 01:00까지처럼 종료 시각이 더 작게 보이는 경우, 다음 날 옵션을 켜면 1시간 30분으로 계산합니다.

### 3) 회의·상담·공부 기록을 분 단위로 정리할 때
총 분과 소수 시간이 같이 나오므로 스프레드시트, 업무일지, 공부 시간 기록에 옮기기 쉽습니다.

## 사용 예시
- 시작: 09:00
- 종료: 18:00
- 휴게시간: 60분

→ 총 경과시간: **9시간 0분**
→ 순수 시간: **8시간 0분**

자정 넘김 예시는 다음처럼 계산합니다.

- 시작: 23:30
- 종료: 01:00
- 종료 시각이 다음 날: 켬

→ 총 경과시간: **1시간 30분**

## 계산 방식
- 총 경과시간 = 종료 시각 − 시작 시각
- 자정 넘김 옵션 사용 시 종료 시각에 **24시간**을 더해 계산
- 순수 시간 = 총 경과시간 − 휴게시간
- 소수 시간 = 총 분 ÷ 60
- 휴게시간이 총 경과시간보다 길면 순수 시간은 0분으로 보정

## FAQ
### 시작/종료 시각이 같으면 어떻게 되나요?
자정 넘김 옵션을 끄면 0시간 0분으로 계산됩니다. 자정 넘김을 켜면 24시간으로 계산됩니다.

### 휴게시간이 총 경과시간보다 길면 어떻게 되나요?
순수 시간은 0으로 보정됩니다. 음수 작업시간은 표시하지 않습니다.

### 종료 시각이 더 빠르면 자동으로 다음 날로 계산하나요?
아니요. 실수 입력일 수 있어서 먼저 오류로 안내합니다. 실제로 자정을 넘긴 일정이면 `종료 시각이 다음 날` 옵션을 직접 켜면 됩니다.

### 결과 복사에는 어떤 내용이 들어가나요?
총 경과시간, 순수 시간, 총 분, 소수 시간, 차감 휴게시간, 날짜 처리 상태가 함께 들어갑니다.

### 모바일에서도 바로 쓸 수 있나요?
네. 브라우저에서 바로 계산되며 별도 설치가 필요 없습니다.
