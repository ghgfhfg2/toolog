## 랜덤 추첨기, 이런 상황에서 바로 써보세요
- 이벤트 댓글/신청자 중 **당첨자 뽑기**
- 스터디·모임에서 **발표 순서 랜덤 결정**
- 팀 프로젝트에서 **무작위 팀 배정**
- 여러 후보 중 하나를 고르는 **간단 제비뽑기**

명단만 붙여넣고 당첨 인원만 정하면 바로 결과가 나옵니다.

## 오늘 개선 선택 기준
최근 품질 개선 이력이 `pomodoro-timer`, `readability-checker`, `time-difference-calculator`, `korean-name-romanizer`, `png-compressor`, `json-merge`, `link-list-cleaner` 등에 집중되어 있어 같은 툴 반복을 피했습니다.
`lucky-draw-picker`는 실제 이벤트나 모임에서 바로 공유할 결과를 만드는 picker형 도구라, 빈값·중복명·당첨 인원 초과·모바일 복사 흐름 같은 오류 가능성과 사용성 보강 가치가 커 오늘 개선 대상으로 골랐습니다.

## 사용 방법
1. 참여자 이름을 한 줄에 한 명씩 입력하거나 쉼표로 구분해 붙여넣습니다.
2. 당첨 인원을 `1명 이상`으로 입력합니다.
3. **추첨하기** 버튼을 누릅니다.
4. 중복 제거 수와 실제 당첨 인원을 확인합니다.
5. **결과 복사**로 번호가 붙은 당첨자 목록을 공유합니다.

예시 입력과 초기화 버튼도 있어 모바일에서 테스트하고 다시 추첨하기 쉽습니다.

## 추첨 규칙
- 앞뒤 공백 제거
- 빈 줄 제외
- 중복 이름 제거 및 중복 제거 건수 표시
- 쉼표로 붙여넣은 목록도 분리
- 당첨 인원은 `1 ~ 고유 참여자 수` 범위로 제한
- 추첨은 브라우저의 난수를 사용하고 서버로 명단을 보내지 않음

## 오류를 줄이는 입력 팁
### 1) 같은 사람이 다른 표기로 들어갔는지 확인
`김민준`, `김 민준`, `민준`처럼 표기가 다르면 서로 다른 참여자로 볼 수 있습니다. 공식 명단 기준으로 이름을 맞춘 뒤 추첨하는 편이 안전합니다.

### 2) 당첨 인원을 먼저 작게 넣어 테스트
실제 이벤트 전에 예시 입력이나 소규모 명단으로 한 번 눌러보면 복사 결과 형식과 모바일 화면 흐름을 확인할 수 있습니다.

### 3) 발표 순서 정하기에도 사용
당첨 인원을 전체 참여자 수와 같게 넣으면 무작위 발표 순서나 게임 순서를 정하는 용도로도 쓸 수 있습니다.

## FAQ
### 참여자 순서가 당첨 확률에 영향을 주나요?
아니요. 입력 순서와 상관없이 동일 확률로 추첨합니다.

### 모바일에서도 동작하나요?
네. 브라우저에서 작동하므로 모바일/PC 모두 사용 가능합니다.

### 서버로 데이터가 전송되나요?
아니요. 계산은 브라우저에서만 처리되어 명단이 외부로 전송되지 않습니다.

### 쉼표로 붙여넣은 명단도 되나요?
네. 줄바꿈뿐 아니라 쉼표로 이어진 명단도 참여자 단위로 나눠 처리합니다. 다만 이름 자체에 쉼표가 들어간 경우에는 줄바꿈 입력을 권합니다.

### 당첨 인원을 잘못 크게 넣으면 어떻게 되나요?
고유 참여자 수보다 큰 값은 실제 참여자 수까지만 자동으로 줄이고, 상태 문구로 조정 사실을 알려줍니다.
