## 평균 계산기, 이런 상황에서 유용해요
시험 점수, 운동 기록, 지출 내역, 설문 응답처럼 숫자 목록이 있을 때
**평균만 보는 것보다 중앙값·최솟값·최댓값·범위·사분위수·표준편차까지 함께** 확인하면 더 정확한 판단이 가능합니다.

이 도구는 숫자만 붙여 넣으면 핵심 지표를 즉시 계산해 줍니다.

## 핵심 기능
- 숫자 목록 자동 파싱 (쉼표·공백·줄바꿈 지원)
- 평균(Mean), 중앙값(Median), 합계(Sum) 동시 계산
- 최솟값/최댓값, 범위, 개수 확인
- 1사분위수(Q1), 3사분위수(Q3), 모집단 표준편차 확인
- 천 단위 쉼표와 통화기호가 섞인 숫자 붙여넣기 지원
- 숫자가 아닌 항목 제외 및 제외 개수 표시
- 결과 복사 버튼 제공

## 사용 방법
1. 숫자 목록을 입력합니다.
2. 입력 즉시 결과가 자동 계산됩니다.
3. 숫자가 아닌 항목이 섞여 있으면 제외 개수를 확인합니다.
4. 필요하면 `결과 복사` 버튼으로 요약값을 공유합니다.

## FAQ
### 숫자는 어떤 형식으로 입력하면 되나요?
쉼표, 공백, 줄바꿈 모두 지원합니다. 예를 들어 `12, 18, 30` 또는 줄별 입력 둘 다 가능합니다. `1,000`, `₩2,500`처럼 천 단위 쉼표나 통화기호가 붙은 값도 숫자로 인식합니다.

### 소수점과 음수도 계산되나요?
네. `-2.5`, `3.14`처럼 소수점/음수 입력도 정상 계산됩니다.

### 중앙값은 어떻게 계산되나요?
숫자를 정렬한 뒤 가운데 값을 사용합니다. 데이터 개수가 짝수면 가운데 두 값의 평균을 중앙값으로 계산합니다.

### 표준편차와 사분위수도 볼 수 있나요?
네. 전체 입력을 모집단으로 보고 표준편차를 계산하며, 정렬된 값의 아래쪽 절반과 위쪽 절반의 중앙값을 각각 1사분위수(Q1), 3사분위수(Q3)로 표시합니다.

### 숫자가 아닌 값이 섞여 있으면 어떻게 되나요?
문자 항목은 전체를 제외하고 빈 항목은 건너뛰며, 제외된 항목 수를 결과에 표시합니다. 올바른 숫자만 남아 있으면 계산은 계속 진행됩니다.


## 쉼표 구분과 입력 오류 확인
자동 모드는 1,234를 천 단위 표기인 1234로 읽습니다. 1과 234를 각각 계산하려면 모든 쉼표 구분을 선택하세요. 엑셀에서 복사한 값은 한 줄에 숫자 하나 모드로 확인할 수 있습니다. 날짜, 12kg, 10%, 1.2.3 같은 항목은 전체를 제외하며 일부 숫자만 추출하지 않습니다. 통화기호는 ₩, $, ¥, €, £ 접두사를 지원합니다.

### 1,234는 두 숫자인가요?
자동 모드에서는 1234 하나입니다. 1과 234 두 숫자로 계산하려면 모든 쉼표 구분을 선택하세요.

### 입력 한도와 표준편차 기준은 무엇인가요?
최대 5,000개의 비어 있지 않은 항목, 100,000자까지 입력할 수 있고 각 값은 -1,000조부터 1,000조 사이여야 합니다. 문자 항목도 개수 한도에 포함합니다.

이 도구는 모집단 표준편차를 계산합니다. 홀수 개 데이터의 Q1·Q3는 전체 중앙값을 제외한 아래·위 절반의 중앙값입니다. 한 값만 입력하면 두 사분위수는 그 값이고 표준편차는 0입니다. 결과는 최대 소수 8자리로 반올림하며 0 아닌 극소값은 지수 표기로 표시합니다.
