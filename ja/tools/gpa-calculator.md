## 学期末のGPAをすぐ確認したいときに便利
学期末になると、**今学期のGPAがどのくらいになるのか**、
奨学金基準や成績維持条件を超えているかを早く確認したくなります。

このツールでは、科目ごとの単位数と成績を入力するだけで
**加重平均GPA、評価対象単位、総評点、P/除外単位**をすぐに計算できます。
4.5、4.3、4.0の基準を同じ画面で切り替えられるため、学校の制度に合わせたGPA確認に使えます。

## 主な機能
- 科目ごとの単位数 × 成績点による加重平均計算
- 4.5 / 4.3 / 4.0 スケールに対応
- P科目はGPA対象外単位として別集計
- GPA、総評点、反映単位、除外単位をまとめて確認
- 単位数だけ入力して成績がない行、範囲外の単位数を警告
- サンプル入力、クリア、結果コピーに対応

## 使い方
1. GPAスケールを選び、下の評点表が大学の規定と一致するか確認します。
2. 各科目の単位数を入力します。
3. 各科目の成績を選択します。
4. P成績だけを `P` とし、Fは `F` を選んで0点を反映します。
5. GPA、総評点、評価対象単位、P/除外単位を確認します。
6. 必要に応じて結果をコピーし、成績計画やメモに貼り付けます。

## 計算方法
GPAは通常、次のように計算します。

- 各科目の **単位数 × 成績点** を計算
- それらを合計して **総評点** を算出
- 総評点を **評価対象単位数の合計** で割ってGPAを計算

たとえば、3単位のA+科目と2単位のB+科目がある場合、
単純平均ではなく **加重平均** で反映されます。

## FAQ
### なぜP科目はGPAから除外されるのですか？
本ツールはPだけをGPAから除外し、別枠で集計します。Fは0点として単位を分母に含めます。大学独自の規定も確認してください。

### 学校ごとに成績点が少し違っても大丈夫ですか？
スケールだけでなく、下の表の各成績の評点も大学の規定と照合してください。満点が同じでも、各成績の評点が一致するとは限りません。マイナス付きの成績には対応していないため、それらを使う制度のGPAは再現できません。

### 再履修科目はどう入力すればよいですか？
通常は、実際の成績証明書で認定される成績だけを入力するほうが正確です。再履修の扱いは学校ごとに異なる場合があります。

### 入力できる単位数の範囲は？
各科目は0.01〜30単位、小数第2位まで入力できます。不正値や未完成の行があれば全結果とコピーを保留します。

### 目標GPAまで残りどのくらい必要かも分かりますか？
この計算機は科目別の学期GPA確認用です。累積GPAの目標に必要な残り単位の平均GPAを見たい場合は、[目標GPA逆算計算機]({{ '/ja/tools/required-gpa-calculator/' | relative_url }})を使ってください。

## 未入力・入力エラー・コピーの案内
- 何も入力していないときはGPAを表示しません。単位数と成績を入力するか、**サンプル入力**で操作を試せます。
- 使わない行はすべて空欄にしてください。科目名だけ入力した行も、単位数と成績を補うか、行全体を空欄に戻します。
- 単位数が不正、または未完成の行がある場合は、すべての計算結果を非表示にし、修正するまで**結果をコピー**を無効にします。
- P科目だけの場合は除外単位を別に表示しますが、評価対象単位がないためGPAは表示せず、コピーもできません。F科目だけの場合は空欄ではなくGPA 0.00になります。
- **クリア**ですべての科目を消去し、スケールを4.5に戻します。自動コピーを利用できない場合は、画面上の結果を選択して手動でコピーしてください。

## 単位入力と評点表の例
単位は0.01〜30、小数第2位まで入力できます。科目名は任意ですが、名前だけ入力した行も単位と成績を完成させるか削除してください。空行は無視し、未完成の行があれば全結果とコピーを保留します。最大6科目。GPAと総評点は小数第2位に丸めます。

| A0 | 4.0 | 4.0 | 4.0 |
| B+ | 3.5 | 3.3 | 3.3 |
| B0 | 3.0 | 3.0 | 3.0 |
| C+ | 2.5 | 2.3 | 2.3 |
| C0 | 2.0 | 2.0 | 2.0 |
| D+ | 1.5 | 1.3 | 1.3 |
| D0 | 1.0 | 1.0 | 1.0 |
| F | 0 | 0 | 0 |

### PとFの違いは？
PはGPAの分子・分母から除外し、別に集計します。Fは0点ですが単位は分母に含みます。P/F科目だからといってFをPとして入力しないでください。

### スケールを選ぶだけで大学の規定と一致しますか？
いいえ。このページの評点表は本ツールの計算例に使う基準で、マイナス成績には対応しません。評点・再履修・単位認定の規定が異なる場合、公式GPAとは一致しないことがあります。
